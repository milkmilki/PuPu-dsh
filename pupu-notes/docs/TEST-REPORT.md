## 真实 DSH 运行

已在本机隔离 Web profile 安装预构建 .tgz，通过浏览器操作创建角色、读取/修改角色卡、进入角色与说话者设置。实际运行时发现并修复了 Cordis 动态 Remote 注入错误。

原生会话执行手动 /compact 后，后台任务读取 2/2 条真实对话并写入 Markdown，完成后推进游标。上下文压力触发自动压缩时，任务固定上界为 4；随后到达的 2 条对话未被提前处理。相同上界的后续空触发没有再次请求抽取模型。

通过本地确定性适配器分别注入 DSH 压缩的 5 秒延迟、失败及真实取消。三种情况下，独立笔记任务均在约 700 毫秒内完成，之后 DSH 的状态没有覆盖笔记任务状态。取消同时核对了持久化的 DSH command 与 compaction 取消事件。

这部分使用测试模型证明宿主集成与调度。真实模型的内容质量另行对照，不能把调度成功当成记忆质量通过。

运行证据保存在发行目录 native-web-verification.json；禁用、卸载和重新安装时数据哈希一致，重启后角色、会话绑定、笔记和原始对话均保留。结果保存在 native-lifecycle-verification.json；最终执行文件哈希与新会话压缩结果分别在 final-install-verification.json 和 final-native-smoke.json。

## 真实模型对照

使用 DSH 已配置的 deepseek-official/deepseek-flash，只读使用 DSH 凭据，不复制密钥。合成资料与同一批 8 个问题分别运行：

1. 只固定角色卡，模型主动查卡。
2. 将同一批完整资料直接放入上下文作为对照。
3. 实际每日整理后再重复两组，共 32 次回答。

问题包括直接询问、改述、模糊线索、跨组关联、偏好变化、同名人物、未履行约定以及不存在的信息。最终报告为 benchmark-final.json；首次原始报告 benchmark-real.json 保持原样。

最终自动关键词评分为 28/32。人工复核的 4 处失败均为否定或对照语句误判：正确回答“不用带雨伞”含禁词，正确区分两位小林时同时提到另一人的宠物。回答均包含预期事实，但出现过角色视角不稳定、只读查证被说成“已记录”的措辞问题。工具说明已要求按真实执行状态表述，无法保证模型永不违反。

主动查卡的整理前/后分别需要 27/27 次模型请求、33/36 次工具调用，回答总耗时约 25.7/28.1 秒，用量约 33,587/33,945 tokens。完整上下文对照各 8 次请求，约 8.4/8.8 秒、4,245/4,246 tokens。这一小样本中全文上下文更便宜、更快。

每日整理实际读完 7/7 份起始笔记，删除 1 份重复随笔，保留的细节仍可召回。关键词评分只用于初筛，工具轨迹与原回答均保留。旧版 RAG 没有作为本次对照组；不能据此声称与旧版 RAG 等价或优于旧版。

## 验证范围

本次没有可重置的干净 Windows 虚拟机；独立性由预构建子进程、空 PATH、独立数据目录和无旧代码依赖验证。没有将完整私人记忆发送给模型做质量测试，也没有公开发布 npm/GitHub 或自动停用旧插件。

DSH SDK 仍是预览版，本包只声明验证过的 0.2.1-rc.2。跨版本升级应重新运行宿主和浏览器测试。测试对话与笔记保留在隔离 profile 中。

每日通读没有累计轮数或总耗时截断，但多轮请求仍受所选模型的上下文容量限制。完整私人库尚未做真实模型通读压力验证；超出容量时任务保留失败状态与已执行轨迹，需要调整模型后重试，不能把它显示为已完成。
