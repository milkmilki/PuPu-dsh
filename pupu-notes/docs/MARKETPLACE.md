## 简介

把角色的记忆交给角色自己写。每个角色拥有独立 Markdown 笔记，按需要搜索、阅读和整理；支持人设替换、来源查证、历史恢复和旧记忆复制导入。

## 主要功能

- 聊天窗口内分别选择角色与说话者，支持新姓名；开聊后固定身份，可另开对话。
- 角色范围内替换默认 DSH 身份，固定载入可编辑角色卡。
- 一个自然语言笔记工具，完成目录、搜索、阅读、精确编辑、移动和可恢复删除。
- DSH 压缩触发独立对话整理，每日 03:00 后通读笔记；默认沿用对话模型，也可指定整理模型。
- 来源、版本、任务覆盖和错误重试均可在界面查看。
- 旧 SQLite / .pupumem 和新的 .pupunotes 数据包预检；精选分享与完整迁移。
- 独立 MCP 启动入口，不依赖旧 PuPu 或 Python。

## 安装与数据

DSH 安装使用预构建 .tgz。管理入口是“设置 → 蒲蒲笔记”。记忆位于独立 pupu-notes 数据根，卸载软件保留数据；不会接管旧插件会话。

模型只看到当前角色的笔记工具，管理接口由本机管理界面使用。对话和整理使用安装者在 DSH 中选择的模型与凭据；提交给该模型的内容包含它实际阅读的资料。软件包不附带私人记忆或密钥。
