# PuPu Notes implementation contract

Independent source and data. No legacy implementation is copied. Installed old data is read only and imports require a preview and explicit confirmation.

## Vertical slices

1. TypeScript bundle and role-scoped stdio MCP: build, handshake, lifecycle.
2. Markdown notes: scoped file tools, CAS, durable operations, evidence and history.
3. DSH identity replacement and new-session binding: verify dispatched system messages and tool continuation.
4. Committed dialogue, compaction/manual queues and daily full read coverage; durable autonomous model loop and recovery.
5. Lossless legacy projection, full/seed packages and native management UI.
6. Isolated DSH installation, real model/role tests, installable artifacts and evidence report.

## Invariants

- Markdown is the only editable memory truth; SQLite holds evidence, history, jobs and transcripts.
- No automatic retrieval or embedding API. Only the current role card and conversation party names are fixed in context.
- `harness:identity` and deployment identity are scoped overrides, retaining tools and operational context.
- Fixed trigger upper bounds and immutable role ownership. No message-count trigger or cumulative loop limit.
- Per request timeout 180 seconds. Incomplete/cancelled tool arguments never mutate notes.
- Read coverage, writes and cursor commits must be real and replayable. Failures remain visible.
- File deletion removes active notes immediately and retains recoverable revisions.
- Full import preserves every old record and reference; projections are deterministic, incremental, and never overwrite edited notes.
- No public release or real-data distribution is part of implementation.
